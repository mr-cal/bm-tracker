{% from "partials/icon.html" import icon_svg %} {# Navigation: a slim top bar, a bottom tab bar, and a drawer. The top bar used to carry five links in a `nowrap` row, which on a 390px phone made the document 536px wide — the page could scroll sideways, and a sideways document is what makes a fixed bottom bar look like it has vanished. Those links now live in the drawer, behind one button, so the bar has room to breathe and nothing overflows. The drawer is plain CSS driven by `:target` on a hash, so it works before any script has run and needs no framework. `:target` cannot be closed by Escape on its own, so `js/nav.js` adds that one key, plus returning focus to the button that opened it. Icons are SVG, not emoji. Emoji need a colour-emoji font installed; where one is missing they render as a tofu box, which is what the date picker was doing. The drawer and the tab bar are rendered from one list. They were two hand-written lists that had drifted: the tab bar led with Log, the drawer started at Feed, and the only thing they agreed on was the middle.
